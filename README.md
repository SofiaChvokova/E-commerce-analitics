# E-commerce User Behavior Analysis

Аналитический pet-проект по исследованию поведения пользователей интернет-магазина.

## Цель

Исследовать пользовательский путь от просмотра товара до покупки, оценить конверсию, удержание и ценность покупателей, а также определить основные закономерности, влияющие на бизнес-метрики.

## Данные

Датасет содержит около 885 тыс. событий интернет-магазина электроники:

- view
- cart
- purchase

Период наблюдений: сентябрь 2020 — февраль 2021.

## Что исследовано

- предобработка и проверка качества данных
- пользовательские сессии
- EDA
- продуктовая воронка
- conversion rate
- анализ товарных категорий
- анализ ценовых сегментов
- статистическая проверка гипотез
- Activity Retention
- Purchase Retention
- когортный анализ
- повторные покупки
- Observed LTV

## Основные результаты

- View → Cart: 7.73%
- Cart → Purchase: 47.92%
- User Conversion: около 5.2%
- M1 Activity Retention полноценных когорт: около 2–3%
- M1 Purchase Retention: около 1.6–2.5%
- Repeat Purchase Session Rate: 11.53%
- около 96–97% Observed LTV формируется в месяц первой покупки
- рост выручки в январе был практически полностью связан с ростом продаж видеокарт

## Инструменты

Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, Statsmodels.
